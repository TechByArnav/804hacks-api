How it works

Measurement model

01
Energy model

Base kWh per second at 100% CPU, scaled by language factor and memory ratio.

02
Carbon intensity

Real-time VA-DOM grid intensity (g CO₂/kWh) from PJM API.

03
Emission = Energy × Intensity

kWh × g CO₂/kWh = grams of CO₂ per code execution.
