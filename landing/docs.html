Technical Reference

API Reference

REST endpoints for Virginia grid carbon intensity, code energy estimation, and emission analysis. Base URL: http://localhost:8000/api/v1

Endpoints
GET /carbon/intensity GET /carbon/intensity/history GET /carbon/forecast GET /carbon/hourly GET /carbon/generation-mix POST /code/analyze GET /carbon/compare GET /grid/status GET /carbon/equivalents
Carbon Intensity

GET /carbon/intensity

Get current Virginia (DOM zone) carbon intensity in lb CO₂/MWh and g CO₂/kWh.

GET /carbon/intensity

Returns the latest real-time carbon intensity for the Virginia Dominion zone.

Query real_time (boolean, default: true)

Response

{
  "timestamp": "2026-10-18T14:21:57.690923Z",
  "carbon_intensity_lb_per_mwh": 761.5,
  "carbon_intensity_g_per_kwh": 345.4,
  "region": "VA-DOM",
  "source": "fallback_estimate",
  "is_real_time": false
}
Historical Data

GET /carbon/intensity/history

Retrieve historical carbon intensity at 5-minute intervals.

GET /carbon/intensity/history
Query hours (integer, 1–168, default: 24)

Example

GET /carbon/intensity/history?hours=24

GET /carbon/forecast

Hourly Intensity

GET /carbon/hourly

24-hour carbon intensity from 1 AM through 12 AM, with scheduling summary for carbon-aware job planning.

Code Analysis

POST /code/analyze

Estimate energy consumption and CO₂ emissions for a code snippet across 11 languages.

POST /code/analyze

Request Body

{
  "code": "def fib(n): return n if n<=1 else fib(n-1)+fib(n-2)",
  "language": "python",
  "runtime_seconds": 5,
  "cpu_utilization": 0.5,
  "memory_mb": 256
}

Response

{
  "estimated_energy_kwh": 1e-6,
  "estimated_emissions_g_co2": 0.0004,
  "carbon_intensity_used_g_per_kwh": 345.4,
  "breakdown": {
    "cpu_wh": 0.001,
    "memory_wh": 0.0,
    "idle_wh": 0.0,
    "total_wh": 0.001,
    "language": "python"
  },
  "timestamp": "2026-10-18T14:21:45.896309Z"
}
